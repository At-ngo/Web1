# Web1– Watch Store
- Dự án xây dựng giao diện website bán đồng hồ, gồm 2 phần chính: User và Admin.
- Repository bao gồm toàn bộ mã nguồn giao diện, CSS, JS, hình ảnh và các trang chức năng.

## Trang User
Mở file:
- `index.html`

## Trang Admin
Mở file:
- `admin_login.html`
## Cấu trúc thư mục
```
├── admin/                 # Giao diện & chức năng dành cho Admin
├── bootstrap-5.0.2-dist/  # Bootstrap
├── css/                   # CSS dành cho user
├── cssadmin/              # CSS dành cho admin
├── image/                 # Hình ảnh giao diện user
├── img/                   # Hình ảnh admin
├── js/                    # JavaScript
├── login_user/            # Các trang cho người dùng đã đăng nhập và sử dụng được giỏ hàng đặt hàng
├── user/                  # Các trang cho người dùng chưa đăng nhập
├── admin_login.html       # Trang đăng nhập admin
├── index.html             # Trang chính của user
└── README.md              # File mô tả dự án
